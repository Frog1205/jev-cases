    Jev 使用教程

    5 个使用入口 + 3 个案例集，从注册到上手一页看完。

    一、注册登录和使用

    唯一官方网站：https://typesafe.ai/

    其他站点都是逆向或者接入官方 API 的方式，使用时注意甄别。

    使用前注意：Jev 核心的几个元素

    01

    state

    输入条件，可以是自然语言，但不支持多模态。

    02

    场景

    可以单独给出，也可以嵌入到 state 中。

    03

    输出参数

    指定输出参数类型：

    choice可以是多个选择 noulyes/no，可以多个维度 score按业务选维度打分
