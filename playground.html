需要在本地配置环境变量

API Key 和接口地址只从本机环境变量读取，不会出现在网页里。配置后重启本地服务：

setx TypeSafe_Key "你的 Jev API Key"
setx DEEPSEEK_API_KEY "你的 DeepSeek API Key"
setx TYPESAFE_BASE_URL "https://api.typesafe.ai"   （可选，第三方平台可改成 https://jevmodel.org）
setx DEEPSEEK_BASE_URL "https://api.deepseek.com"  （可选）
python playground_server.py   然后打开 http://127.0.0.1:8787/playground.html
